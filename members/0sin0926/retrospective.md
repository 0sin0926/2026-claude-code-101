## 3. 워크플로우

- 초반(3주차)
    1. 일단 큰 틀에서 원하는 기능과 서비스의 목적을 설명한 다음 목업 수준의 파일만 구현했음
    2. 한 줄 한 줄 시켰음. "이 파일 이렇게 고쳐줘" 수준.
     → 내가 세세하게 지시해야 해서 오히려 내가 더 바빴음.
    
- 중반
    1. 기능 단위로 맡기기 시작. "음성 등록 기능 만들어줘" → 알아서 파일 찾고 구현.
    

- 후반(6주차)
    1. 목적만 던지고, 자잘한 판단은 위임.
    → 나는 방향/우선순위 결정 + 실제 화면에서 검증, Claude는 구현.
    → 반복 작업(빌드 트리거, 리팩터, 커밋)은 거의 자동으로.
    2. 로그인·랜딩페이지 같은 큰 기능도 하나하나 명령하지 않음.
    → plan mode로 목적만 전달 → Claude가 구현 계획을 먼저 제안
    → 내가 계획을 검토·승인한 뒤 구현 시작

## 4. 배운 것

- 무턱대고 시작하는 것이 아니라, 미리 계획과 기능을 정리해놓고 명확히 명령할 것
    
    → 초기에 구현을 0부터 시작할 때 큰 오류 없이 빠르게 구현하는 데 도움을 줌
    
- clone해서 다른 프로젝트를 레퍼런스로 사용할 때는 빠른 이해를 위해 /init 과 같은 기능을 충분히 활용할 것
    
    +hook과 같은 나만의 기능을 활용하여 생산성 올리기
    

- 디자인이나 기능 등을 머리싸매고 고민할 시간에 일단 만들어보기

## 5. 아쉬운 것

- AI가 만든 코드를 다 이해하지 못한 채 넘어간 부분이 있어, 나중에 학습 부채로 남음.
- 일단 구현하는 것에 급급해서 다양한 기능 (mcp, plugin)을 충분히 활용하지 못 한 것
